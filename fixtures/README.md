# fixtures

The committed demo dataset. **Do not edit these files by hand** — they are generated, and CI fails
the build if they drift from the generator.

```bash
pnpm fixtures:generate          # regenerate (deterministic; byte-identical output)
pnpm fixtures:generate --check  # what CI runs — fails on drift
```

| File | Contents |
| --- | --- |
| `manifest.json` | Seed, window bounds and counts. Also carries the data disclaimer. |
| `catalog.json` | 12 brands, 6 categories, 3 platforms, 240 products. |
| `series.json` | 78 weekly points per product: bid/ask/last-sale and volume/listings. |
| `attribute-trends.json` | Monthly share of transaction value per colour, material and category. |
| `editorial.json` | 3 personas, 5 sources, 12 analyst notes with entity links, 8 reports. |
| `ops.json` | Ingestion history, feature flags, subscriptions. |

Loaded by the `fixture` market-data provider ([ADR-0001](../docs/adr/0001-provider-adapter.md)) and
by `pnpm db:seed`.

## Notice

`fixtures/` contains a synthetic market dataset generated by
`scripts/generate-fixtures.ts`. Product names reference real silhouettes for
realism; **all prices, volumes and listing counts are synthetic** and do not
represent any real market, and the style codes are generated rather than real
catalogue identifiers. See the README's "About the dataset" section.
